# 业有来处 · 内部工作台

**这个仓库如果还是公开的，请改成私有。** 里面会写下项目、事实和报价结构，不适合放在公开仓库里。

字标「业有来处」里，「来」的最后一笔用了橙色。这是内部工作用的视觉设想，不是已注册商标。英文写 YE YOU LAI CHU。

## 这是什么

给李波、丁雷、熊健新在自己电脑上用的工作台。用来把一个真实故事整理成手绘动态影像短片的工作稿：立项、事实、分镜、报价和进度。

不是对外页面，也没有登录。

分工只记角色：

- 李波：选题 / 剧本 / 审美
- 丁雷：客户与回款
- 熊健新：播出渠道对接
- 制作外包

## 怎么运行

需要 Node.js 20 或更高版本。

```bash
pnpm install
pnpm dev
```

浏览器打开 <http://localhost:3000>。

项目数据写在本机 `data/store.json`，这个文件已被 gitignore。备份时复制它即可。

不要把端口暴露到公网。

## 报价金额

仓库里没有真实价格。档位名称是占位：开发、短剧、系列。

金额放在下面任意一处。环境变量优先于本机文件。`config/pricing.example.json` 里的数字不会被采用，以免真实报价被提交。

1. 复制 `config/pricing.example.json` 为 `config/pricing.local.json`，把 `amount` 改成数字，单位是人民币元。
2. 或复制 `.env.example` 为 `.env.local`，去掉对应行的注释再填写。

改完刷新报价页。还没填时，报价单写「未配置」，不会显示编造的金额，也不会用 0 代替。

连通测试可以先写任意数字。不要把真实报价写进会被提交的文件。

## v1 能做什么

- 立项：公司或人物、已知、待核、成片用途、手头材料
- 事实板：每条标成已确认、待核或演绎，并写来源。已确认必须有来源。演绎句始终标着「非事实」
- 分镜：时长、画面（手绘动态影像）、旁白、上屏文字。可以放入一套约 2 分 30 秒的样片结构
- 报价单：按档位试算，打印，或下载 Markdown
- 进度：接谈 → 开发 → 样片 → 交付，以及权利、审片、交付清单
- 脚本稿：可打印，也可下载 Markdown

《在边上》可以当作「样片开发中」的空项目开始。工具不会预填生平。
